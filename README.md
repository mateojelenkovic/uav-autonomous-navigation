# Autonomous UAV Navigation

An independent research project focusing on developing an autonomous UAV path-planning and obstacle-avoidance algorithms using Python and C++.

## Project Obective

Develop a simulated UAV capable of navigating through enviornments containing obstacles, calculating efficient paths, and responding to changing enviornments.

## Technologies

- Python
- Matplotlib
- C++ (planned)

## Current Progress

- Created a 2D obstacle-grid enviornment
- Implemented Breadth-First Search (BFS)
- Implemented path reconstruction
- Visualized calculated paths using Matplotlib

## Future Development

- Dijkstra's Algorithm
- A* Pathfinding
- C++ implementation
- Dynamic obstacle avoidance and replanning
- ROS 2 integration
- AI-based autonomy extensions
